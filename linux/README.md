# Linux, Python and ROS 2 (planned)

Packages for Linux robots: a Python package for Raspberry Pi and Jetson, and ROS 2 packages
(`alloy_storage_ros`) built with colcon.

Today, Linux and ROS 2 robots upload to Alloy Storage with **Alloy Edge**, Alloy's on-device agent,
which is distributed separately. Set it up from the Alloy app.
